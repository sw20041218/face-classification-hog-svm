# 冻结 ResNet18 与 HOG 联合分类

本轮使用冻结的 ImageNet 预训练 ResNet18，输入灰度图按 MATLAB 列优先恢复方向，双线性缩放为 96×96，复制三通道，按 ImageNet 均值 [0.485,0.456,0.406] 与标准差 [0.229,0.224,0.225] 标准化。

layer2 的 2×2 池化为 512 维、layer3 的 2×2 池化为 1024 维、layer4 的全局池化为 512 维；各分支 L2 归一化、拼接并再次归一化，共 2048 维。与 685 维对比度/HOG 按 [基础特征,0.5×迁移特征] 拼接并归一化，共 2733 维。

单个 SVM 仅拟合原始 800 张训练图及水平镜像，共 1600 个视图，每视图权重 0.5。最佳为 RBF 核、C=1、gamma=0.5，原图与镜像分数平均，阈值 -0.856203979708998。人工参考标签用于选择融合、核、参数、推理方式和阈值，403/420=95.9524% 是开发集成绩，不是独立测试准确率。
